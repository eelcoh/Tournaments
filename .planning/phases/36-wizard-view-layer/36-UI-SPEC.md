## Spacing Scale

All values are multiples of 4. Source: existing codebase conventions in `Form/Bracket/View.elm`.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | `Element.spacing 4` — tightest inline gaps (minimap dot label gap: 3px exception below) |
| sm | 8px | `Element.spacing 8` — badge row spacing, inner badge column gap |
| md | 12px | `Element.spacing 12` — badge grid column gap |
| lg | 16px | `Element.spacing 16` — between group sections in R32 grid |
| xl | 24px | not used in this phase |
| 2xl | 48px | not used in this phase |
| 3xl | 64px | not used in this phase |

Exceptions:
- Minimap dot-to-label gap: `Element.spacing 3` (pre-existing, keep as-is — not a new token)
- Touch target height for all badges: `Element.px 44` regardless of content (meets 44px minimum touch target)
- Sticky "Ga verder" button bottom padding: `Element.padding 16`

| Role | Size | Weight | Line Height | Usage |

| Group header | 12px | regular (400) | n/a (single line) | Amber group letter label in R32 grid (e.g. `"A"`) |

Maximum declared sizes: 4 (9px / 10px / 11px / 12px). Maximum weights: 2 (regular 400 + medium 500).

## Badge States (Three-State Model)

Source: CONTEXT.md "Badge states in active grid".

### Active Grid (current round being filled)

| State | Border | Background | Text | Flag | Click |
|-------|--------|------------|------|------|-------|
| **Can select** | `Color.terminalBorder` (1px) | `Color.primaryDark` | `Color.primaryText` (11px) | Normal | `SelectTeam round team` |
| **Selected in this round** | `Color.terminalBorder` (1px) | `Color.primaryDark` | `Color.grey` (11px) | Grey veil (rgba 0 0 0 0.45 via `Element.inFront`) | `DeselectTeam team` |
| **Cannot select** (max reached) | `Color.terminalBorder` (1px) | `Color.primaryDark` | `Color.grey` (11px) | Grey veil (rgba 0 0 0 0.45 via `Element.inFront`) | none (no `onClick`) |

Mouse hover (desktop only): selectable badges get `Element.mouseOver [ Border.color Color.orange ]`.

### Placed Section (rounds above the active round)

| State | Border | Background | Text | Click |
|-------|--------|------------|------|-------|
| **Placed / confirmed** | `Color.green` (1px) | `Color.primaryDark` | `Color.green` (11px) + `Color.grey` (9px sub-code) | `DeselectTeam team` |

## R32 Group Header Format

Source: CONTEXT.md "R32 group header format".

- Single letter only: `"A"` through `"L"` — not `"-- A --"`
- Color: `Color.terminalAccentDim` (amber `#CC9966`)
- Size: 12px, `UI.Font.mono`
- Displayed inline above the badge rows for that group
- All 12 groups always visible — no groups hidden when all members are dimmed
- Teams already selected in R32 round remain in their group position, shown as "selected in this round" state (dimmed + veil), NOT hidden

## Active Grid Dispatch

Source: CONTEXT.md "Active grid dispatch".

`viewActiveGrid` dispatches on `SelectionRound`:

```
LastThirtyTwoRound -> viewR32Grid  (group-organized, all 48 teams)
_                  -> viewFlatGrid (flat pool from prior round)
```

`viewFlatGrid` pool sources:
- `LastSixteenRound`: `sel.lastThirtyTwo` (32 teams)
- `QuarterRound`: `sel.lastSixteen` (16 teams)
- `SemiRound`: `sel.quarters` (8 teams)
- `FinalistRound`: `sel.semis` (4 teams)
- `ChampionRound`: `sel.finalists` (2 teams)

On Computer: `viewActiveGrid` for all rounds uses the flat group-row layout (`viewGroup`), not `viewFlatGrid`. The 360px column threshold applies to Phone only.

## Interaction Contracts

### JumpToRound
- Tapping any minimap dot calls `JumpToRound r` — sets `wizardState.viewingRound`
- Completed rounds can be revisited; active grid shows that round's full pool

### SelectTeam
- Only fired when `canSelectTeam round team sel teamData_` returns True
- Adds team to the current round's field in `RoundSelections`

### DeselectTeam
- Fires from: placed badge (confirmed section) OR selected-in-round badge (active grid)
- Removes team from its round AND cascades removal from all subsequent rounds (handled by state layer — Phase 35)

### GoNext
- Fires only when `isWizardComplete sel` is True (sticky button visible)
- Advances wizard to `TopscorerCard` via existing `nextRound`-based mechanism

## Viewport Constraint

Source: STATE.md "Phase 36: Manual render check required at 320px viewport".

All badge grids MUST render without horizontal overflow at 320px viewport width:
- R32/R16: 4 columns × 48px + 3 gaps × 12px = 228px — fits within 320px with page padding
- QF–Champion at < 360px: 2 columns × 80px + 1 gap × 12px = 172px — fits within 320px with page padding
- Page horizontal padding: `paddingXY 16` (existing `UI.Page.page` convention)

Manual render check at 320px is required after implementation (noted in STATE.md blockers).
